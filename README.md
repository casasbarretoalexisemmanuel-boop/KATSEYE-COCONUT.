# KATSEYE Coconut 💗

Prototipo no oficial para Android.

## Compilación

Abre **Actions → Compilar APK Android**. La compilación se inicia automáticamente al subir código a `main`. Cuando finalice, descarga el artefacto **KATSEYE-Coconut-APK**, que contiene `app-debug.apk`.

## Limitaciones

- Busca el dispositivo BLE `KATSEYE OLS`.
- Los UUID y comandos BLE son **experimentales y no verificados con hardware**; puede conectar sin controlar las luces.
- El modo música reacciona al volumen captado por el micrófono, **no reconoce canciones ni sincroniza coreografías oficiales**.
- No afiliada a KATSEYE ni al fabricante.
