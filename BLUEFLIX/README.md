# BLUEFLIX Android

Proyecto independiente de KATSEYE LIGHTSYNC. Esta carpeta se reserva para BLUEFLIX 1.1 con catálogo, reproductor, favoritos, perfiles y administración de videos con Supabase.

**Estado:** estructura de integración iniciada; aún falta subir los archivos del proyecto Android, configurar Supabase y verificar una compilación APK. No colocar claves privadas en GitHub.

El código fuente está disponible en el ZIP BLUEFLIX_Android_Admin_1.1_source.zip entregado en ChatGPT. Copiar el contenido de su carpeta BLUEFLIX/ a esta carpeta del repositorio, preservando las rutas. La compilación se configurará con un workflow separado para no interferir con la app del lightstick.
